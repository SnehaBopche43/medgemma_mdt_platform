# MedGemma MDT Platform

## Overview
AI-powered Multidisciplinary Team (MDT) case preparation platform using Google's MedGemma.

## Features
- Multimodal medical imaging analysis (CT/MRI/Pathology)
- Longitudinal treatment response tracking
- Automated MDT case brief generation
- Quality assurance and anti-hallucination checks
